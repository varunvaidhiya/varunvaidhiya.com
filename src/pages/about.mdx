## Experience

### OhhO Robotics — Founder & Perception / Robotics Software Engineer
*Oct 2024 – Present*

Founded OhhO Robotics and built a full-stack robotics operating platform (25K+ lines, ROS 2 Jazzy) spanning perception, VLA inference, teleoperation, simulation, data pipelines, and fleet operations — productising a full embodied-AI stack from research prototype to deployable software.

- Built multi-camera bird's-eye-view perception (4 wide-angle feeds → unified top-down via per-camera homographies with RANSAC/checkerboard calibration, CPU-only at 30 Hz)
- Engineered persistent 3D spatial mapping fusing RGB-D 3D SLAM (RTAB-Map) and 3D occupancy mapping (OctoMap) with wheel-odometry/IMU EKF state estimation
- Trained and fine-tuned multimodal Vision-Language-Action networks (SmolVLA, OpenVLA) in PyTorch, served behind a REST API (pluggable backends, Prometheus metrics)
- Optimised perception and policy inference for edge hardware via TensorRT FP16/INT8 and ONNX Runtime (2–3x vision-encoder speed-up, under 5% output deviation, sub-200 ms end-to-end latency)
- Built an end-to-end demonstration-data pipeline (LeRobot v2.0 format) with distributed training and W&B experiment tracking

### Five AI — MSc Dissertation Researcher, Autonomous Vehicle Perception
*Dec 2023 – Oct 2024*

- Fine-tuned SAM 2 on autonomous driving datasets (Cityscapes) using distributed training, systematic hyperparameter optimisation, and W&B experiment tracking
- Benchmarking vision foundation models on embedded platforms (Jetson Orin, RTX mobile GPU) — inference latency, memory footprint, and model performance
- Optimised deep learning inference pipelines using Nsight Systems/Compute; applied INT8/FP16 quantisation, TensorRT optimisation, and custom CUDA kernels (30% inference time reduction on RTX 4070 mobile)
- Investigated model compression (knowledge distillation, quantisation-aware fine-tuning, pruning) for deploying large-scale transformers on resource-constrained edge hardware
